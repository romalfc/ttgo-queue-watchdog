# TTGO RTOS tasks

Проєкт для LILYGO T3 V1.6.1 на ESP32. Програма визначає одинарне та подвійне натискання кнопки, передає результат через FreeRTOS-черги та відправляє LoRa-пакети через SX1276.

## Схема роботи

```text
Кнопка -> ButtonTask -> buttonQueue -> loop() -> radioQueue -> RadioTask -> LoRa
```

- `ButtonTask` опитує кнопку, усуває дребезг і визначає тип натискання.
- `buttonQueue` передає подію натискання та час її отримання в головний цикл.
- `loop()` формує пакет потрібного розміру.
- `radioQueue` зберігає пакет і час його постановки в чергу.
- `RadioTask` ініціалізує SX1276 і виконує передачу.
- Якщо діє duty cycle, нові пакети залишаються в `radioQueue` і передаються після завершення очікування.

## Апаратна конфігурація

| Пристрій | Параметр | GPIO |
| --- | --- | ---: |
| OLED | SDA | 21 |
| OLED | SCL | 22 |
| OLED | RESET | -1 |
| LoRa SX1276 | CS | 18 |
| LoRa SX1276 | DIO0 | 26 |
| LoRa SX1276 | DIO1 | 33 |
| LoRa SX1276 | RESET | 23 |
| Кнопка BOOT | вхід | 0 |

OLED SSD1306 працює за адресою I2C `0x3C`.

Апаратні параметри оголошені через `#define` на початку [src/main.cpp](src/main.cpp), тому їх можна змінити для іншої плати або модуля.

## Налаштування

Основні параметри:

```cpp
#define LORA_TX_POWER 2
#define LORA_FREQUENCY 868.0
#define RADIO_PACKET_SIZE 64
#define SINGLE_RADIO_PACKET_SIZE 32
#define LORA_DUTY_CYCLE_PERCENT 1
#define DEVICE_IDLE_SLEEP_MS 60000
#define DOUBLE_CLICK_THRESHOLD_MS 350
```

- Одинарне натискання передає пакет розміром 32 байти.
- Подвійне натискання передає пакет розміром 64 байти.
- Duty cycle встановлено на 1%.
- Після 60 секунд без успішної передачі пристрій переходить у `light sleep`.
- Під час сну OLED показує `Hibernation...`.
- Команда через UART пробуджує пристрій.
- Після пробудження лічильник відправлених пакетів обнуляється.

## Команди Serial Monitor

Швидкість Serial Monitor: `115200` baud.

Команди потрібно завершувати клавішею Enter:

| Команда | Дія |
| --- | --- |
| `single-btn` | Імітує одинарне натискання, пакет 32 байти |
| `double-btn` | Імітує подвійне натискання, пакет 64 байти |
| `double-btn 1000` | Імітує два натискання з інтервалом 1000 мс |

Для команди `double-btn <мс>`:

- якщо інтервал більший за `DOUBLE_CLICK_THRESHOLD_MS`, у `buttonQueue` додаються дві події `Single`, і передаються два пакети по 32 байти;
- якщо інтервал менший або дорівнює порогу, додається одна подія `Double`, і передається один пакет 64 байти;
- допустимий інтервал: від 100 до 2000 мс.

Якщо передача очікує завершення duty cycle, подія не втрачається: вона зберігається в черзі та буде передана після дозволу наступної передачі.

Після пробудження від `light sleep` перший байт команди пробуджує ESP32, а повна команда обробляється через Serial Monitor.

## Індикація OLED

Під час передачі дисплей показує розмір і стан пакета:

```text
32 byte packet sending...
```

або:

```text
64 byte packet sending...
```

Після передачі відображаються:

- загальна кількість успішно відправлених пакетів від останнього пробудження;
- кількість пакетів, що очікують у чергах (`Queued`);
- час до переходу в сон;
- час виконання останньої передачі (`Last TX`).

Приклад основного статусу:

```text
32 byte packet sent
Total sent: 3
Queued: 2
To sleep: 42 s
Last TX: 120 ms
```

Під час duty-cycle очікування:

```text
Duty cycle wait
Next TX in: N ms
Queued: N
```

Після завершення очікування:

```text
Ready to send
Next TX in: 0 ms
```

`Queued` враховує події в `buttonQueue` та пакети в `radioQueue`. Детальний відлік `Next TX in` показується тільки на OLED.

У Serial Monitor під час очікування виводиться одне повідомлення:

```text
Radio task: waiting for duty cycle
```

Після отримання події `RadioTask` також виводить затримку від моменту введення команди або натискання кнопки до початку передачі:

```text
Radio task: command-to-TX delay=123 ms
```

## Збірка та прошивка

Відкрийте проєкт у VS Code з PlatformIO і виконайте:

```bash
pio run --environment ttgo-lora32-v2
pio run --target upload --environment ttgo-lora32-v2 --upload-port COM6
pio device monitor --environment ttgo-lora32-v2 --port COM6
```

Порт `COM6` замініть на актуальний порт плати.

Також можна використовувати кнопки PlatformIO: **Build**, **Upload** і **Monitor**.

##  Залежності

Залежності визначені у [platformio.ini](platformio.ini):

- Adafruit SSD1306
- Adafruit GFX Library
- RadioLib

## Обмеження

- Частота `868 MHz` і потужність передавача повинні відповідати вашому модулю та місцевим радіочастотним нормам.
- Duty cycle 1% означає обов'язкову паузу після передачі. Наступний пакет відправляється одразу після завершення розрахованого відліку.
- GPIO0 є кнопкою BOOT. Не утримуйте її під час скидання або завантаження прошивки, якщо не потрібно перейти в режим програмування.
